# HarborView Wealth — Retirement and Liquidity

A retirement plan should consider spending needs, time horizon, expected income sources, liquidity reserves, taxes, and the possibility of adverse market sequences. A portfolio that has an attractive long-run expected return can still create difficulty if large losses occur when withdrawals are required.

Liquidity reserves can reduce the need to sell volatile assets during unfavorable markets. The appropriate reserve depends on expected spending, income stability, and other available resources.

Rules of thumb can be useful starting points but should not be treated as guarantees or personalized recommendations without a suitability analysis.
